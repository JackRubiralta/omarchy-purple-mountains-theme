# Purple Mountains

A dark [Omarchy](https://omarchy.org) theme: near-black surfaces, soft white text and a violet-blue accent lifted from the purple-mountains wallpaper. Built with Aether, packaged as a standalone theme.

![Purple Mountains preview](preview.png)

## Install

```sh
omarchy theme install https://github.com/JackRubiralta/omarchy-purple-mountains-theme
```

Or in Omarchy: **Super + Alt + Space → Install → Style → Theme** and paste the URL above. The theme shows up as **purple-mountains** in the theme switcher.

The focused-window border is a violet-to-orchid gradient (`hyprland_active_border`), which the Omarchy shell reuses for popup and notification borders.

Everything else (terminals, btop, Neovim via aether.nvim, the Omarchy shell, Hyprland borders, Chromium, VS Code, Obsidian, …) is generated by Omarchy from `colors.toml`.

## What's inside

```
colors.toml          palette (Omarchy 4 semantic format) + the gradient window border
icons.theme          Yaru-magenta
keyboard.rgb         keyboard backlight colour for supported laptops (accent)
backgrounds/         1-purple-mountains.jpg (the wallpaper), omarchy.webp (plain branded wallpaper in the palette)
unlock.png           lock-screen wordmark in the violet-to-orchid gradient
preview.png          shown in the theme switcher and on themes.omarchy.org
preview-unlock.png   lock-screen preview for the Style > Unlock picker
```

Terminal configs, Neovim and VS Code are generated by Omarchy from `colors.toml` on install, so this repo does not ship them (Omarchy drops those files from git-installed themes anyway).

## Requirements

Omarchy 4.x. Older Omarchy 3 installs can still use the palette: Omarchy derives the missing files from `colors.toml`.
