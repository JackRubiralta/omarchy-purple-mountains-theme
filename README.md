# Purple Mountains

A dark [Omarchy](https://omarchy.org) theme: near-black surfaces, soft white text and a violet-blue accent lifted from the purple-mountains wallpaper. Built with Aether, packaged as a standalone theme.

![Purple Mountains preview](preview.png)

## Install

```sh
omarchy theme install https://github.com/JackRubiralta/omarchy-purple-mountains-theme
```

Or in Omarchy: **Super + Space → Install → Style → Theme** and paste the URL above. The theme shows up as **purple-mountains** in the theme switcher.

## Optional: window transparency

Omarchy doesn't run Lua from a theme installed with `omarchy theme install`, so the transparency is a short snippet you add yourself. Paste it at the end of `~/.config/hypr/looknfeel.lua`; Hyprland reloads when you save.

It uses Omarchy's own lists, so it follows whatever Omarchy counts as a terminal or a transparent app:

| Group | Omarchy list | Apps (Omarchy 4.5) | Focused | Unfocused |
|---|---|---|---|---|
| Terminals | `terminal` tag | Ghostty, Alacritty, kitty, foot, WezTerm, and Omarchy's own terminal windows (btop, TUIs, …) | 87.5 % | 80 % |
| Transparent apps | `transparent-window` tag | Nautilus, omawrite, LocalSend, 1Password (if installed), and any window you turn see-through with **Super + Backspace** | 98.5 % | 92.5 % |
| Everything else | none | Browsers, video, games, chat apps, … | 100 % | 100 % |

```lua
-- Purple Mountains window transparency ("<focused> <unfocused>").
-- Terminals also carry the transparent-window tag, so their line comes last.
-- Matching class and title as well makes Hyprland re-apply both lines when a
-- window's title changes, so Omarchy's default opacity never flickers back.
o.transparent_window({ class = ".*", title = ".*", tag = "transparent-window" }, "0.985 0.925")
o.transparent_window({ class = ".*", title = ".*", tag = "terminal" }, "0.875 0.8")
```

Everything else stays solid because Omarchy keeps it solid; the snippet doesn't touch it. To make another app transparent, add it to Omarchy's list above the snippet: `o.transparent_window("org.gnome.TextEditor")` (find the class with `hyprctl clients`).

## Optional: Firefox

Omarchy doesn't theme Firefox, so the theme ships a matching Firefox theme in `firefox/`: the same near-black toolbar and tabs, soft white text, the violet-blue accent on the outline of the selected tab, tab loading indicator, focused address bar and highlighted menu items, muted grey icons, and no separator lines. It also sets Firefox and websites to dark mode.

It isn't signed by Mozilla, so Firefox needs to allow unsigned add-ons first (this works on Arch's `firefox` package):

1. Open `about:config` and set `xpinstall.signatures.required` to `false`.
2. Open `about:addons`, click the gear, choose **Install Add-on From File…** and pick `~/.config/omarchy/themes/purple-mountains/firefox/purple-mountains.xpi`.

For a thicker outline around the selected tab (2px instead of 1px), which a Firefox theme can't set by itself:

3. In `about:config`, set `toolkit.legacyUserProfileCustomizations.stylesheets` to `true`.
4. Copy `firefox/userChrome.css` into a `chrome` folder inside your Firefox profile (`about:support` → **Profile Folder** → Open), then restart Firefox.

`firefox/manifest.json` is the source. After changing it, rebuild the add-on with `cd firefox && zip -X purple-mountains.xpi manifest.json`.

## What's inside

```
colors.toml          palette (Omarchy 4 semantic format)
icons.theme          Yaru-magenta
keyboard.rgb         keyboard backlight colour for supported laptops (accent)
firefox/             matching Firefox theme: manifest.json (source), purple-mountains.xpi, userChrome.css (thicker selected-tab outline)
backgrounds/         1-purple-mountains.jpg (the wallpaper), omarchy.webp (plain branded wallpaper in the palette)
unlock.png           lock-screen / boot-splash wordmark in the accent colour
preview.png          shown in the theme switcher and on themes.omarchy.org
preview-unlock.png   boot-splash thumbnail for the Plymouth unlock-screen switcher (generated with `omarchy plymouth preview`)
```

Terminal configs, Neovim and VS Code are generated by Omarchy from `colors.toml` on install, so this repo does not ship them (Omarchy drops those files from git-installed themes anyway).

## Requirements

Omarchy 4 (Quattro) or newer. The theme is a `colors.toml` palette, which Omarchy 3 does not read.
